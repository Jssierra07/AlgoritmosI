SINOPSIS DEL SISTEMA:
El programa desarrollado simula de manera lógica y funcional la administración de un parqueadero de vehículos con capacidad limitada (5 cupos), controlado mediante una interfaz de consola interactiva. El código fue estructurado bajo la metodología de programación modular.
EXPLICACIÓN DETALLADA DE LAS FUNCIONALIDADES:
1. MENÚ INTERACTIVO Y FLUJO CONTINUO (MÓDULO `main` y `mostrarMenu`):
  - Funcionalidad: Permite al usuario navegar permanentemente entre las opciones disponibles mediante la consola.
  - Justificación Técnica: Utiliza un ciclo estructurado "do-while" controlado por una variable bandera tipo booleana ('salir'). La evaluación de opciones se realiza mediante un control de flujo múltiple ("switch-case"), garantizando eficiencia O(1) en la redirección de tareas.
2. REGISTRO DE INGRESO DE VEHÍCULOS (MÓDULO `registrarIngreso`):
  - Funcionalidad: Permite la entrada de autos validando la disponibilidad de celdas físicas en tiempo real.
  - Justificación Técnica: Emplea un arreglo unidimensional de Strings para guardar las placas. Mediante un ciclo repetitivo ascendente (for) busca secuencialmente espacios con el valor "VACÍO". Si encuentra espacio, inserta el dato; si el arreglo está lleno, activa una condición de control informando la saturación de cupos. incrementa de forma unitaria la variable de conteo de vehículos.
3. PROCESAMIENTO DE SALIDA Y FACTURACIÓN (MÓDULO `registrarSalida`):
  - Funcionalidad: Libera las posiciones del arreglo y calcula automáticamente la deuda financiera del usuario según el tiempo transcurrido.
  - Justificación Técnica: Solicita el índice del arreglo. Cuenta con sentencias lógicas y relacionales de validación anidada (evita que se intente liberar un cupo inválido o ya vacío). Realiza una operación matemática de resta aritmética (Hora Salida - Hora Ingreso) y multiplica por una constante estricta de tarifa. El resultado es acumulado en la variable global 'recaudacionTotal'.
4. DIAGNÓSTICO DE MEMORIA EN VIVO (MÓDULO `mostrarEstadoParqueadero`):
  - Funcionalidad: Muestra gráficamente el estado actual de cada uno de los slots del arreglo.
  - Justificación Técnica: Recorre la estructura de datos simple mediante un ciclo iterativo imprimiendo los índices activos y los strings guardados, demostrando el control directo de las variables en memoria.
5. CONTROL DE EFICIENCIA Y REPORTE (MÓDULO `mostrarEstadisticas`):
  - Funcionalidad: Imprime el consolidado final del uso del sistema antes de cerrar la sesión.
  - Justificación Técnica: Expone los datos finales calculados mediante variables de conteo y sumatoria de acumulación.
ANALISIS DE EFICIENCIA (BIG-O):
  - Las búsquedas y recorridos de los arreglos se realizan en un tiempo lineal O(N) donde N es la cantidad de cupos.
  - El acceso por índice específico para cobro directo opera con una eficiencia óptima de tiempo constante O(1).
